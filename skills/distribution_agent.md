# Distribution Agent — Skill Definition

## Role
Multi-channel content distribution and revenue operations specialist.
Posts content to WordPress and social platforms, tracks all revenue events,
and generates financial performance reports.

## Capabilities
| Task Type          | Description                                         | Avg Duration |
|--------------------|-----------------------------------------------------|--------------|
| `post_content`     | Publish blog post to WordPress + generate social    | 5–30s        |
| `social_post`      | Post text/media to Twitter, LinkedIn                | 2–10s        |
| `financial_report` | Generate revenue breakdown report                   | <1s          |

## Inputs
```json
{
  "post_content": {
    "topic": "string",
    "blog_filepath": "/path/to/post.md",
    "image_filepath": "/path/to/hero.png (optional)",
    "title": "Post title",
    "blog_task_id": "UUID"
  },
  "social_post": {
    "topic": "string",
    "text": "Post text (max 280 chars for Twitter)",
    "platform": "twitter|linkedin|youtube"
  },
  "financial_report": {}
}
```

## Outputs
```json
{
  "post_content": {
    "type": "distribution",
    "topic": "...",
    "wordpress": {"id": 123, "link": "https://...", "status": "published"},
    "social_snippet": "Tweet text generated by LLM"
  },
  "financial_report": {
    "type": "financial_report",
    "total_revenue_usd": 1234.56,
    "breakdown": [{"source": "stripe", "total_usd": 1000, "month": "2026-03"}],
    "posts_by_platform": {"wordpress": 42, "twitter": 38}
  }
}
```

## WordPress Integration
- **Auth**: HTTP Basic Auth with Application Password
- **Endpoint**: `WP_URL/wp-json/wp/v2/posts`
- **Media**: Auto-uploads featured image before post creation
- **Format**: Raw HTML (converted from Markdown)
- **Status**: Published immediately (`"status": "publish"`)

## Revenue Tracking
- **Storage**: SQLite (`./data/revenue.db`)
- **Tables**: `revenue_events`, `posts`
- **Sources**: Stripe webhooks, manual records, affiliate payouts
- **Reports**: Monthly breakdown by source, cumulative totals

## Social Snippet Generation
After each WordPress post:
- LLM generates a Twitter/X post (≤280 chars)
- Includes 2-3 hashtags + CTA
- Queued for `social_post` task

## Scaling Notes
- Max 3 concurrent (I/O bound, not compute bound)
- WordPress posting serialized per-site to avoid duplicate slugs
- SQLite writes use connection-per-operation pattern (thread-safe)
